# 보이지 않는 도시들: 한국어 3D 아틀라스

이탈로 칼비노의 *보이지 않는 도시들(Invisible Cities)*에서 마르코 폴로가 쿠빌라이 칸에게 들려주는 **55개의 도시**를, 체스판 위의 작은 3D 풍경으로 탐험하는 웹 프로젝트입니다. 도시마다 코드로 생성한 건축물과 움직임이 있으며, 도시의 설명과 두 인물의 대화를 따라 책의 구성을 살펴볼 수 있습니다.

이 저장소는 **[stared의 원본 프로젝트](https://github.com/stared/invisible-cities-opus-5.5)를 한국어로 현지화한 포크**입니다. 원본의 3D 도시와 시각적 구성을 바탕으로, 도시 설명과 화면 인터페이스를 한국어로 옮겼습니다.

**[한국어판 바로 열기](https://sigco3111.github.io/invisible-cities-opus-5.5/)** · [원본 저장소](https://github.com/stared/invisible-cities-opus-5.5) · [보존된 영어 README](README.en.md)

> 이 프로젝트의 본문은 소설 전문이나 출판된 한국어 번역문이 아닙니다. 원본 저장소가 아틀라스용으로 작성한 영어 재서술을 한국어로 옮긴 것입니다. 책 자체를 읽는 경험을 대신하지 않습니다.

## 프로젝트에서 할 수 있는 것

### 55개 도시를 탐험하기

도시 하나하나가 작은 디오라마입니다. 도자기와 황동을 떠올리게 하는 건축물, 물과 빛, 도시별 애니메이션을 가까이에서 살펴보고 한국어 설명을 읽을 수 있습니다. 도시 생성 코드는 `src/cities/`에, 공통 건축 요소는 `src/kit.js`에 있습니다.

### 세 가지 배열로 책의 구조 보기

- **지도**: 11개 분류의 도시를 각각 1~5번으로 배열합니다. 바닥의 빛나는 선은 마르코가 도시를 이야기하는 순서를 나타냅니다.
- **여정**: 읽는 순서대로 도시를 나선형으로 배치합니다. 중심에는 베네치아가 있습니다.
- **장**: 9개 장을 행으로 펼칩니다. 장별 도시 수는 `10, 5, 5, 5, 5, 5, 5, 5, 10`입니다.

### 대화와 자동 여행

- 체스판 앞쪽의 **칸의 정원 정자**를 누르면 마르코 폴로와 쿠빌라이 칸의 대화를 읽을 수 있습니다.
- **여행 모드**에서는 55개 도시를 순서대로 방문하며 장 사이의 대화도 함께 보여 줍니다.
- **목차**에서는 장과 도시 분류를 따라 원하는 도시로 이동할 수 있습니다. 작은 화면에서는 장별 세로 목록으로 표시됩니다.

### 분위기 바꾸기

도시 분류 필터, 황혼과 밤 조명, 실시간 생성 사운드, 틸트 시프트, 블룸과 필름 그레인이 포함되어 있습니다. 소리는 미리 녹음한 음악이 아니라 코드로 생성하는 사운드스케이프입니다.

## 한국어화 범위와 구현

### 번역한 내용

- **55개 도시**: 한국어 표시명, 짧은 소개, 본문.
- **10개 대화**: 제목과 본문.
- **화면 인터페이스**: 시작 화면, 메뉴, 분류, 목차, 도움말과 탐색 안내.

### 원본과 분리한 번역 데이터

번역 데이터는 [`src/locale-ko.js`](src/locale-ko.js)에 모았습니다. 도시의 한국어 이름은 별도 `displayName`으로 두고, 본문은 명시적인 두 문단으로 나눴습니다. `src/data.js`에서 원본 데이터와 한국어 데이터를 연결합니다.

도시의 **영어 ID, 원래 영어 이름, 생성기 이름과 난수 시드는 유지**했습니다. 화면에는 한국어 이름을 보여 주지만, `zaira`, `octavia` 같은 내부 키와 URL의 도시 식별자는 바뀌지 않습니다. 한국어 이름 때문에 다른 도시 모델이 선택되거나 난수 기반 풍경이 달라지지 않도록 한 구성입니다.

### 한글 읽기에 맞춘 표시

- **Noto Serif KR 400**을 패키지에 포함해 사용합니다. 한글 글꼴을 외부 글꼴 서버에서 받아오지 않습니다.
- 한글 본문의 행간, 첫 글자 장식과 도시 표시명 폭을 조정했습니다.
- 작은 화면의 목차를 장별 세로 목록으로 바꿨습니다.
- 자동 여행에서 한국어 본문과 대화의 표시 시간을 더 길게 잡았습니다. 개인의 읽기 속도에 따라 충분하지 않을 수 있으므로, 필요하면 여행을 일시정지해 읽으세요.

## 시작하기

설치 없이 보려면 [배포된 한국어판](https://sigco3111.github.io/invisible-cities-opus-5.5/)을 여세요. 소스를 실행하거나 수정하려면 아래 순서를 따릅니다.

### 준비물

- Git.
- **Node.js 24** 권장. 배포 워크플로도 Node.js 24를 사용합니다.
- **pnpm**. 저장소의 `package.json`에는 `pnpm@12.3.4`가 지정되어 있습니다.
- WebGL2를 지원하는 최신 브라우저. Chrome 또는 Edge 등의 브라우저에서 하드웨어 가속을 켜는 것을 권합니다.

### 소스 받기와 실행

```sh
git clone https://github.com/sigco3111/invisible-cities-opus-5.5.git
cd invisible-cities-opus-5.5
pnpm install --frozen-lockfile
pnpm dev
```

브라우저에서 **http://127.0.0.1:5199**를 여세요. 포트가 이미 사용 중이면 다른 포트가 선택될 수 있으므로 터미널에 표시된 주소를 확인하세요.

첫 화면에서 도시 생성이 끝날 때까지 기다린 뒤 **지도 펼치기**를 누릅니다. 55개 도시를 생성하므로 기기에 따라 초기 로딩에 시간이 걸릴 수 있습니다.

## 조작 방법

도시를 클릭하면 해당 도시로 이동하고 설명 패널을 엽니다. 화면의 메뉴로 배열, 목차, 여행, 조명과 소리를 바꿀 수 있습니다.

| 키 | 동작 |
| --- | --- |
| `←` / `→` | 이전 / 다음 도시 |
| `↑` / `↓` | 같은 분류 안에서 도시 이동 |
| `1` / `2` / `3` | 지도 / 여정 / 장 배열 |
| `T` | 자동 여행 시작 / 일시정지 |
| `C` | 목차 열기 / 닫기 |
| `N` | 황혼 / 밤 조명 전환 |
| `M` | 소리 켜기 / 끄기 |
| `H` | 인터페이스 숨기기 / 표시 |
| `Esc` | 뒤로 가기 |

### 특정 도시 바로 열기

도시의 영어 ID를 URL 해시에 넣습니다. 한국어 이름이 아니라 원본 ID를 사용합니다.

```text
http://127.0.0.1:5199/#zaira
http://127.0.0.1:5199/#octavia
```

시작 화면이 먼저 보이면 **지도 펼치기**를 누르세요.

도시 하나만 렌더링하는 모드도 있습니다. `scripts/shot.mjs`는 이 모드를 도시 스크린샷 촬영에 사용합니다.

```text
http://127.0.0.1:5199/?solo=octavia&view=side
```

## 빌드와 미리보기

```sh
pnpm build
pnpm preview --host 127.0.0.1
```

- 빌드 결과는 **`dist/`**에 생성됩니다.
- 미리보기 주소는 터미널 출력을 확인하세요. 현재 빌드는 GitHub Pages 하위 경로를 사용하므로, 미리보기에서도 `/invisible-cities-opus-5.5/` 경로로 접속합니다.
- `dist/index.html`을 더블클릭해 여는 `file://` 실행은 지원하지 않습니다. HTTP 서버로 제공해야 합니다.
- 다른 도메인의 루트나 다른 하위 경로에 배포하려면 `vite.config.js`의 `base`를 대상 경로에 맞게 바꾼 후 다시 빌드하세요.

> `scripts/serve-dist.mjs`는 `dist/`를 루트 경로에서 제공하는 간단한 서버입니다. 현재 Pages용 빌드 경로와는 맞지 않으므로 그대로 사용하기보다 위의 `pnpm preview`를 사용하세요. 이 README에서는 기존 스크립트나 앱 코드를 변경하지 않았습니다.

브라우저에서 http://127.0.0.1:5199를 여세요. 포트가 이미 사용 중이면 다른 포트가 선택될 수 있으므로 터미널에 표시된 주소를 확인하세요.

첫 화면에서 도시 생성이 끝날 때까지 기다린 뒤 **지도 펼치기**를 누릅니다. 55개 도시를 생성하므로 기기에 따라 초기 로딩에 시간이 걸릴 수 있습니다.

## 조작 방법

도시를 클릭하면 해당 도시로 이동하고 설명 패널을 엽니다. 화면의 메뉴로 배열, 목차, 여행, 조명과 소리를 바꿀 수 있습니다.

| 키 | 동작 |
| --- | --- |
| `←` / `→` | 이전 / 다음 도시 |
| `↑` / `↓` | 같은 분류 안에서 도시 이동 |
| `1` / `2` / `3` | 지도 / 여정 / 장 배열 |
| `T` | 자동 여행 시작 / 일시정지 |
| `C` | 목차 열기 / 닫기 |
| `N` | 황혼 / 밤 조명 전환 |
| `M` | 소리 켜기 / 끄기 |
| `H` | 인터페이스 숨기기 / 표시 |
| `Esc` | 뒤로 가기 |

### 특정 도시 바로 열기

도시의 영어 ID를 URL 해시에 넣습니다. 한국어 이름이 아니라 원본 ID를 사용합니다.

```text
http://127.0.0.1:5199/#zaira
http://127.0.0.1:5199/#octavia
```

시작 화면이 먼저 보이면 **지도 펼치기**를 누르세요.

도시 하나만 렌더링하는 모드도 있습니다. `scripts/shot.mjs`는 이 모드를 도시 스크린샷 촬영에 사용합니다.

```text
http://127.0.0.1:5199/?solo=octavia&view=side
```

## 빌드와 미리보기

```sh
pnpm build
pnpm preview --host 127.0.0.1
```

- 빌드 결과는 `dist/`에 생성됩니다.
- 미리보기 주소는 터미널 출력을 확인하세요. 현재 빌드는 GitHub Pages 하위 경로를 사용하므로, 미리보기에서도 `/invisible-cities-opus-5.5/` 경로로 접속합니다.
- `dist/index.html`을 더블클릭해 여는 `file://` 실행은 지원하지 않습니다. HTTP 서버로 제공해야 합니다.
- 다른 도메인의 루트나 다른 하위 경로에 배포하려면 `vite.config.js`의 `base`를 대상 경로에 맞게 바꾼 후 다시 빌드하세요.

> `scripts/serve-dist.mjs`는 `dist/`를 루트 경로에서 제공하는 간단한 서버입니다. 현재 Pages용 빌드 경로와는 맞지 않으므로 그대로 사용하기보다 위의 `pnpm preview`를 사용하세요. 이 README에서는 기존 스크립트나 앱 코드를 변경하지 않았습니다.

## GitHub Pages 배포

현재 한국어판은 다음 주소에 배포되어 있습니다.

**https://sigco3111.github.io/invisible-cities-opus-5.5/**

배포 설정은 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)에 있습니다.

1. 저장소의 **Settings → Pages**에서 소스를 **GitHub Actions**로 설정합니다.
2. **Actions → Deploy to GitHub Pages**에서 **Run workflow**를 실행합니다.
3. 워크플로가 Node.js 24와 pnpm으로 의존성을 설치하고 `pnpm build`를 실행합니다.
4. `dist/`를 Pages 아티팩트로 올린 뒤 배포합니다.

현재 워크플로는 **`workflow_dispatch`를 통한 수동 실행만** 받습니다. 커밋을 푸시하는 것만으로 사이트가 자동 재배포되지는 않습니다.

`vite.config.js`는 개발 서버에서는 `/`, 프로덕션 빌드에서는 `/invisible-cities-opus-5.5/`를 `base`로 사용합니다. 다른 이름의 포크에 배포한다면 이 경로도 새 저장소 이름에 맞춰 수정해야 합니다.

## 문제 해결

- **`pnpm` 명령을 찾을 수 없어요**: pnpm을 설치하고 `pnpm --version`으로 확인하세요. 가능하면 `package.json`에 지정된 버전에 맞춥니다.
- **잠금 파일 관련 설치 오류가 나요**: 먼저 지정된 pnpm 버전인지 확인하세요. `--frozen-lockfile`은 의존성이 잠금 파일과 일치할 때만 설치하도록 하는 옵션입니다. 오류를 피하려고 잠금 파일부터 지우지 마세요.
- **화면이 비거나 도시가 보이지 않아요**: WebGL2 지원과 브라우저 하드웨어 가속 설정을 확인하고, 최신 브라우저에서 다시 열어 보세요.
- **첫 화면에서 오래 기다려요**: 도시 전체를 생성하는 단계가 있습니다. 다른 무거운 탭을 닫고 생성이 끝날 때까지 기다려 보세요.
- **빌드 후 JS·CSS를 찾지 못해요**: 서버의 제공 경로와 `vite.config.js`의 빌드 `base`가 일치하는지 확인하세요. 현재 값은 Pages 프로젝트 경로입니다.
- **소리가 나지 않아요**: 먼저 화면을 클릭해 시작하고 소리 버튼 또는 `M`으로 켜 보세요. 브라우저의 자동 재생 제한으로 사용자 조작 전에는 소리가 시작되지 않을 수 있습니다.
