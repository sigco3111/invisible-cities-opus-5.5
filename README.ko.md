# 보이지 않는 도시들: 한국어판

원본: https://github.com/stared/invisible-cities-opus-5.5

55개 도시의 이름·짧은 소개·본문, 대화 10개의 제목·본문, 메뉴·분류·목차·도움말을 번역했습니다.
원본의 영어 이름과 ID는 유지하고 한국어 표시명을 별도로 둡니다.

## 실행

Node.js 22.12 이상 또는 24 LTS와 pnpm이 필요합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시되는 주소를 브라우저로 여세요. 기본 주소는 http://127.0.0.1:5199 입니다.
자이라를 바로 열려면 주소 뒤에 `/#zaira`를 붙이고 '지도 펼치기'를 누르세요.
최신 Chrome/Edge 등 WebGL2 지원 브라우저와 하드웨어 가속을 권합니다.
55개 도시를 생성하므로 첫 화면에서 잠시 기다려야 합니다.

## 빌드와 오프라인 실행

```sh
pnpm build
node scripts/serve-dist.mjs
```

빌드 결과인 `dist/`와 위 서버 스크립트가 있으면 패키지 설치 없이 실행할 수 있습니다.
ZIP 예비본에는 `dist/`도 들어 있습니다. GitHub 소스에서는 먼저 빌드하세요.
`dist/index.html`을 더블클릭하는 `file://` 방식은 지원하지 않습니다.
한글 글꼴은 빌드 안에 포함되며 외부 글꼴 서버에 연결하지 않습니다.

## 변경점

- 영어 `id`, 원래 `name`, 생성기 이름과 난수 시드는 유지합니다.
- `src/locale-ko.js`에 번역과 별도 `displayName`을 둡니다.
- 도시 본문은 명시적인 두 문단으로 나눴습니다.
- Noto Serif KR 400을 포함하고 한글 행간·첫 글자 장식·표시명 폭을 조정했습니다.
- 작은 화면의 목차는 장별 세로 목록으로 바꿨습니다.
- 자동 여행은 한국어 본문에서 읽는 시간을 더 길게 잡습니다. 실제 읽기 속도에 따라 추후 조정할 수 있습니다.
- 빌드 경로를 상대 경로로 바꾸고 GitHub Pages의 push 자동 배포를 해제했습니다.

본문은 원작 인용문이나 출판된 한국어 번역문이 아니라, 이 저장소의 영어 재서술을 한국어로 옮긴 것입니다.
